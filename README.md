## 👨‍💻 About me

I'm **Gabriel Andrade**, also known as **Andrade-11**, a Software Engineer and Full-Stack Developer based in Porto Alegre, Brazil.

My work ranges from maintaining and modernizing legacy systems to designing and building new web, mobile and backend applications.

I work across the entire development lifecycle — architecture, frontend, backend, databases, integrations, deployment and infrastructure.

My main stack currently revolves around **React, Vite, Java, Spring Boot and PostgreSQL**, with additional experience in Angular, Ionic, Laravel, Node.js, Docker, AWS and Cloudflare.

I'm especially interested in **software architecture, distributed systems, AI applications, RAG, semantic search and engineering leadership**.

## 🚀 What I'm working on

### 🥋 TatamiApp

Management platform for Brazilian Jiu-Jitsu academies.

I joined the project maintaining an existing stack based on **Angular, Ionic, Laravel and PostgreSQL/MySQL**.

Later, I led a major modernization of the platform, rebuilding its architecture with:

* React
* Vite
* Tailwind CSS
* Java
* Spring Boot
* PostgreSQL
* Docker
* Cloudflare
* Stripe

The project includes academy management, students, classes, payments, graduations, gamification, onboarding and administrative workflows.

I also developed a **mobile application using Expo / React Native**, expanding the platform beyond the original web system.

---

### 🏆 Tatami Arena

Competition management and scoring platform designed for combat sports tournaments.

The application includes different workflows for:

* Tournament organizers
* Athletes
* Scorekeepers

Core features include:

* Tournament management
* Mat management
* Competition scoreboards
* Athlete registration
* Payments
* PIX and Stripe integration
* Competition history
* Integration with the TatamiApp ecosystem

Built primarily with **React, Vite, Tailwind CSS and reusable architecture extracted from the Tatami ecosystem**.

---

### 🧪 PETLab

Full modernization of a legacy veterinary laboratory management system.

The project involves replacing and refactoring an existing system while preserving complex laboratory workflows and historical data.

Responsibilities include:

* Legacy system analysis
* Full-stack development
* Database migration and modeling
* Laboratory request workflows
* Exam management
* Attachments
* Medical reports
* Dynamic PDF generation
* Operational dashboards
* User and permission flows

Current architecture:

* React
* Vite
* Tailwind CSS
* Java
* Spring Boot
* PostgreSQL / MySQL

The legacy database contains more than **100 tables and several gigabytes of production data**, requiring careful domain modeling and migration strategies.

---

### 🤖 OpenDataSUS AI Assistant

AI research and development project focused on making Brazilian public health data easier to query and understand.

The system is designed to combine **OpenDataSUS data with Large Language Models using Retrieval-Augmented Generation (RAG)**.

Research areas include:

* RAG
* LLMs
* Embeddings
* Semantic Search
* pgvector
* PostgreSQL
* OpenDataSUS APIs
* Structured and semi-structured health data
* Local and open-source AI models

The initial research focus is **immunization data**.
